# Estructura de secciones / Manuscript Section Structure

## Español

Los archivos de manuscrito se crearán únicamente cuando la fase correspondiente esté desbloqueada. No se crearán borradores vacíos que puedan confundirse con contenido aprobado.

Estructura objetivo provisional:

1. `01_introduction.md`
2. `02_related_work.md`
3. `03_methods.md`
4. `04_results.md`
5. `05_discussion.md`
6. `06_limitations.md`
7. `07_conclusions.md`
8. `abstract.md`
9. `title_and_keywords.md`

Cada archivo deberá contener primero `## Español` y luego `## English`, con equivalencia científica completa.

La estructura final puede cambiar en Fase 0D según el target journal y la contribución central aprobada.

---

## English

Manuscript files will be created only when the corresponding phase is unlocked. Empty draft files will not be created if they could be mistaken for approved content.

Provisional target structure:

1. `01_introduction.md`
2. `02_related_work.md`
3. `03_methods.md`
4. `04_results.md`
5. `05_discussion.md`
6. `06_limitations.md`
7. `07_conclusions.md`
8. `abstract.md`
9. `title_and_keywords.md`

Each file must contain `## Español` first and `## English` second, with complete scientific equivalence.

The final structure may change in Phase 0D according to the target journal and the approved central contribution.
