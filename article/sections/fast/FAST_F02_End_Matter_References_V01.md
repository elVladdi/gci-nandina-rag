# Data availability

The administrative and reference inputs used in the governed study are not represented as publicly redistributable. Public code, configuration contracts, documentation, and reproducibility resources are available in the public repository `elVladdi/gci-nandina-rag-reproducibility`, audited at commit `254831cd955103faa2517065a7eed7fb340bbccc`. Reproduction of the exact reference study may require access to restricted or otherwise non-redistributed inputs.

# Code and reproducibility resources

The public reproducibility repository documents reference, custom, and synthetic modes; data and provenance contracts; the experiment protocol; taxonomy and normative-corpus configuration; reproducibility guidance; and use with compatible user-supplied data. The audited public snapshot supports inspection and progressive reproduction or replication workflows, but it is not represented as a complete one-command fresh-clone end-to-end reproduction of the full reference study, and repository availability does not establish deployment readiness.

## Spanish semantic mirror materialized blocks

# Disponibilidad de datos

Los insumos administrativos y de referencia utilizados en el estudio gobernado no se presentan como públicamente redistribuibles. El código público, los contratos de configuración, la documentación y los recursos de reproducibilidad están disponibles en el repositorio público `elVladdi/gci-nandina-rag-reproducibility`, auditado en el commit `254831cd955103faa2517065a7eed7fb340bbccc`. La reproducción exacta del estudio de referencia puede requerir acceso a insumos restringidos o no redistribuidos.

# Código y recursos de reproducibilidad

El repositorio público de reproducibilidad documenta los modos de referencia, personalizado y sintético; los contratos de datos y procedencia; el protocolo experimental; la configuración de la taxonomía y del corpus normativo; la guía de reproducibilidad; y el uso con datos compatibles proporcionados por el usuario. El snapshot público auditado permite la inspección y flujos progresivos de reproducción o replicación, pero no se presenta como una reproducción completa de extremo a extremo, desde un clon limpio y mediante un único comando, del estudio de referencia; la disponibilidad del repositorio tampoco establece preparación para despliegue.
