# Gobernanza común de fichas G3–G8

1. El usuario conserva la decisión final.
2. Codex ejecuta únicamente la ficha/prompt activo.
3. IA Experimental audita independientemente antes de cualquier transición científica.
4. `CREATED/DEFINED ≠ EXECUTED ≠ VERIFIED ≠ APPROVED ≠ INTEGRATED ≠ CLOSED`.
5. No se reinterpretan resultados para hacer pasar una hipótesis o gate.
6. No se cambian métricas, umbrales, poblaciones o exclusiones después de observar resultados salvo protocolo nuevo, prospectivo y separado.
7. SERIE sigue siendo unidad de análisis; DAM/DECLARACIÓN se usa como agrupamiento cuando hay dependencia.
8. EVAL v0.2 permanece congelado en 1,056 casos; no se mezclan particiones incompatibles.
9. EXP11A solo autoriza conclusiones de sensibilidad; no efecto causal aislado del tamaño.
10. EXP12 está cerrado sin retrieval; su efecto de diversidad histórica no es estimable y no puede reconstruirse post hoc.
11. Todo análisis futuro de 0B-05C debe usar Attempt06 corregido.
12. Las limitaciones `DECLARED_NOT_RECOVERABLE` y `HASH_BOUND_LOCAL_ONLY` permanecen visibles.
13. Cada ficha debe producir evidencia versionada y un reporte suficiente para auditoría externa.
14. Ninguna ficha de Grupos 4–8 puede alterar resultados científicos cerrados por Grupo 3.
15. Si una fuente requerida no está disponible, se bloquea la ficha; no se completa por memoria o inferencia.

## Activación

Antes de ejecutar cada ficha se debe registrar: SHA `main`, SHA Plan Maestro, SHA del artículo si aplica, fuentes de entrada, outputs esperados, prohibiciones y criterio PASS/FAIL.
