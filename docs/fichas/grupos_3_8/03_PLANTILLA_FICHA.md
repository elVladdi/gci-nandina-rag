# Plantilla obligatoria de ficha

Cada ficha activa debe contener:

1. Identificador, grupo, estado y versión.
2. Objetivo exacto y pregunta que resuelve.
3. Precondiciones y SHA de entrada.
4. Fuentes de verdad permitidas.
5. Unidad de análisis/agrupamiento cuando aplique.
6. Acciones obligatorias.
7. Acciones prohibidas.
8. Outputs obligatorios y rutas.
9. Controles de identidad/hashes.
10. Criterios PASS/FAIL/BLOCKED.
11. Limitaciones que deben preservarse.
12. Evidencia mínima para auditoría externa.
13. Estado terminal esperado.
14. Siguiente ficha elegible.

Las fichas prospectivas de este directorio fijan el contenido metodológico; el prompt Codex de ejecución debe materializar los SHA y paths exactos vigentes sin ampliar el alcance.
